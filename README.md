# CYBERGUARD CAMPUS

CYBERGUARD CAMPUS is an integrated cybersecurity monitoring and
incident management platform designed for a controlled university
network laboratory.

## Core pipeline

Network
→ Firewall
→ IDS
→ SIEM
→ CyberGuard API
→ Dashboard
→ Incident
→ Response
→ Resolution

## Platform

- PHP
- MariaDB
- REST API
- Web Dashboard
- Authentication & RBAC
- Incident Management
- Security Monitoring

## Repository structure

- `backend/` — API and application core
- `frontend/` — web interface
- `infrastructure/` — security/network infrastructure
- `docs/` — technical documentation
- `tests/` — integration and security tests
- `scripts/` — operational scripts

## Development rule

All components must be tested, documented, versioned and integrated.
