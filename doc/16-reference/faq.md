# FAQ

**Does the application collect data from the network?**
No. Records reach the database by SQL only. Collection is `PLANNED`; see
[../07-network-monitoring/monitoring-overview.md](../07-network-monitoring/monitoring-overview.md).

**Can it serve several organisations?**
No. There is no tenant model; one installation serves one organisation.

**How do I create a user?**
With SQL, and a bcrypt hash generated by hand: there is no interface or endpoint
([../10-deployment/development.md](../10-deployment/development.md)).

**Why does sign-in answer 415?**
`POST /login` requires `Content-Type: application/json`; that is the login-CSRF protection.

**Why did a wrong method start answering 405 instead of 404?**
Deliberate change: a known path with another method now answers 405 with an `Allow` header.

**Why is there no `Secure` flag on the session cookie?**
Because `APP_ENV` is not `production`. Set it — from `.env`, the web server or the process
environment — and deploy HTTPS first, or the browser will stop sending the cookie.

**Why do the tests fail with status 0 everywhere?**
Apache is not running. Start it and re-run.

**Why do the tests refuse to run?**
`APP_ENV=production`: the suites write and delete data, so they refuse to touch a production
database.

**Where is the audit trail?**
In the `audit_logs` table, for authentication events, and in `incident_history` for incident
changes. There is no interface for either ([../06-security/logging-auditing.md](../06-security/logging-auditing.md)).

**Why is there no pagination?**
Nothing implements it yet; every list endpoint returns the whole table. It is the first item on
the scalability list.

**Can I call the API from a script?**
Yes, with a cookie jar and a real user account. There is no machine credential model
([../08-api/integrations.md](../08-api/integrations.md)).

**Is there a version number?**
No. No tag, no version file: the repository is identified by its commit.

**What is the biggest known risk today?**
The laboratory runs over plain HTTP, so credentials and session cookies are exposed on the
network ([../06-security/threat-model.md](../06-security/threat-model.md)).
